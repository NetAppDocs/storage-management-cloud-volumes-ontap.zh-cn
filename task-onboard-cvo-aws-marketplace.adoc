= 从 AWS Marketplace 订阅和部署 Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
从 AWS Marketplace 订阅 Cloud Volumes ONTAP，让 NetApp Console 指导您完成入门流程。通过从订阅到部署的简单路径，您可以快速启动并运行 Cloud Volumes ONTAP。引导式体验简化了从 AWS Marketplace 订阅到部署的流程，帮助您部署 Cloud Volumes ONTAP，而无需具备丰富的云或 ONTAP 专业知识。

从 AWS Marketplace 订阅和部署 Cloud Volumes ONTAP 包括以下步骤：

* 在 AWS Marketplace 中订阅 Cloud Volumes ONTAP。
* 注册到 Console。
* 创建您的组织（如果需要）并关联 Marketplace 订阅。
* 在 AWS 中部署 Console 代理。
* 添加您的第一个 Cloud Volumes ONTAP 系统。


简化的入门流程为订阅关联、IAM 角色配置、代理配置和系统初始化提供自动化代理部署，所需输入极少。后端编排自动处理 CloudFormation 堆栈创建、VPC 连接验证和资源依赖关系。这减少了手动配置步骤和屏幕切换，让您能够以更少的设置错误和中断更快地部署 Cloud Volumes ONTAP。随着部署的进行，您可以在右侧面板中跟踪进度。

.开始之前
在开始入门工作流之前，请先查看这些先决条件。

* 您需要拥有在 AWS Marketplace 中订阅权限的 AWS 帐户。要使用自动 IAM 设置，您必须是 AWS 管理员或具有以下所示的权限。
+
[source, json]
----
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "CloudFormationStack",
      "Effect": "Allow",
      "Action": [
        "cloudformation:CreateStack",
        "cloudformation:DeleteStack",
        "cloudformation:DescribeStacks",
        "cloudformation:DescribeStackEvents",
        "cloudformation:GetTemplateSummary",
        "iam:CreateRole",
        "iam:DeleteRole",
        "iam:GetRole",
        "iam:PutRolePolicy",
        "iam:DeleteRolePolicy",
        "iam:GetRolePolicy",
        "iam:PassRole",
        "lambda:CreateFunction",
        "lambda:DeleteFunction",
        "lambda:GetFunction",
        "lambda:InvokeFunction"
  ]
}
----
* 您可以在 AWS 中创建或使用 IAM 角色进行代理部署。
* 您可以登录 NetApp Console 或在其中创建帐户。


有关完整的 AWS 代理部署先决条件，请参见 link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html["从 AWS Marketplace 部署 NetApp Console 代理"^]。



[[subscribe-in-aws-marketplace]]
== 在 AWS Marketplace 中订阅

通过在 AWS Marketplace 中找到 Cloud Volumes ONTAP 产品，开始入门流程。

.步骤
. 使用您的 AWS 账户转到 AWS Marketplace。
. 找到 NetApp Cloud Volumes ONTAP 产品。AWS Marketplace 中有两种针对 Cloud Volumes ONTAP 的产品：
+
** Cloud Volumes ONTAP 年度订阅的独立产品
** NetApp 数据服务和 Cloud Volumes ONTAP 订阅的 NetApp 智能服务 (NIS) 组合产品。为此入门工作流程选择_独立_产品。


. 查看列表详情和定价条款。
. 订阅并完成结算。
. 订阅后，AWS 会将您重定向到 Console 注册或登录页面。




[[sign-up-or-sign-in-to-netapp-console]]
== 注册或登录 NetApp Console

完成市场订阅后，请访问控制台继续设置。

.步骤
. 在控制台页面上，选择一项：
+
** 如果您是新用户，请*注册*。
** *登录 NetApp Console*（如果您已有帐户）。


. 如果您选择了*注册*，请完成以下操作：
+
.. 输入必填字段：
+
*** 电子邮件
*** 密码
*** 全名
*** 公司
*** 国家/地区


.. 选择 *Next*。
.. 可选：输入联系方式，如地址、城市、州/省、邮政编码和电话号码。
.. 选择*注册*。
.. 接受许可条款。
.. 使用来自 service@console.netapp.com 的邮件验证您的电子邮件地址。


. 登录到控制台并完成身份验证。




[[create-your-organization]]
== 创建您的组织

仅当您是首次使用的用户或尚未属于 NetApp Console 组织时，才需完成此步骤。

如果您已经属于某个组织，请跳过此部分并继续 <<关联订阅>>。

创建组织以管理用户、角色、权限、许可证和系统。

.步骤
. 输入组织名称。
. 可选：关联 NetApp 支持站点 (NSS) 帐户。
. 选择 *Create*。




[[associate-your-subscription]]
== 关联订阅

创建组织后，Console 会自动尝试将您的市场订阅链接到该组织。

如果自动关联失败，请手动关联您的订阅。link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-subscriptions.html["了解如何管理订阅"^]。



[[deploy-a-console-agent-in-aws]]
== 在 AWS 中部署 Console 代理

关联订阅后，Console 将自动打开代理部署流程，以管理您的 AWS 资源和 Cloud Volumes ONTAP 系统。

有关代理部署期间使用的权限的详细信息，请参见 link:https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html["AWS 权限参考"^]。

.步骤
. 您可以按照介绍页面中提到的步骤，以获得部署代理的最低权限，或继续为代理部署自动创建角色。
. 在 *AWS credentials* 页面上，选择以下选项之一为代理部署提供凭据：
+
[role="tabbed-block"]
====
.为我创建角色（推荐）
--
选择此选项将打开 AWS CloudFormation 快速创建流程以创建代理部署角色。如果您是具有管理员权限的用户，您可以使用此选项自动使用 CloudFormation 堆栈创建策略、角色并对用户进行身份验证以创建代理。

.. 添加 AWS 帐户 ID，也可以添加外部 ID。控制台设置默认角色名称。
.. 确认条款并选择*Create stack*。
+
image:screenshot-stack-creation.png["width=50% AWS CloudFormation 堆栈创建页面的屏幕截图，您可以在其中输入 AWS 账户 ID，也可以输入代理部署角色的外部 ID。"]

.. 在 AWS 中配置 IAM 角色并生成 ARN 时，确认并保存该角色。


--
.承担角色
--
这是手动角色分配工作流程的一部分。输入现有 IAM 角色 ARN。有关编辑此角色的信息，请参阅 https://docs.netapp.com/us-en/console-setup-admin/task-adding-aws-accounts.html#associate-an-existing-subscription-with-your-organization["管理 NetApp Console 的 AWS 凭据和市场订阅"^]。

--
.AWS 密钥
--
这是手动角色分配工作流程的一部分。输入 AWS 访问密钥和私有密钥。有关信息，请参阅 https://docs.netapp.com/us-en/console-setup-admin/task-adding-aws-accounts.html#add-the-credentials-to-an-existing-agent["管理 NetApp Console 的 AWS 凭据和市场订阅"^]。

--
====
. 部署 AWS 代理：
+
.. 在 *AWS agent details* 页面上，设置或确认代理实例名称和代理角色。
.. 在*网络*页面上，选择 VPC、子网、密钥对、公共 IP 行为和代理设置。
.. 配置*安全组*。允许入站 HTTP (80)、HTTPS (443) 和 SSH (22) 以进行代理虚拟机的故障排除访问。


. 查看章节摘要并选择*添加*进行部署。
+
有关完整的网络和权限要求，请参见：

+
** https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-1-set-up-networking["为 AWS Marketplace 部署设置网络"^]
** https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-2-set-up-aws-permissions["设置 AWS 权限"^]
** https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html["AWS 权限参考"^]


. 跟踪部署进度对话框直至完成。您可以展开事件日志以查看详细活动。


.完成后
部署完成后，您可以创建第一个 Cloud Volumes ONTAP 系统，也可以留在系统页面稍后添加系统。



[[add-your-first-cloud-volumes-ontap-system]]
== 添加您的第一个 Cloud Volumes ONTAP 系统

代理准备就绪后，在 AWS 中创建您的第一个 Cloud Volumes ONTAP 系统。

.步骤
. 在部署后提示中，选择*Add system*。
. 启动 Cloud Volumes ONTAP 系统创建工作流。
. 完成系统配置。


要查看详细的系统部署说明，请参阅 https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-quick-deploy-aws.html["在 AWS 中使用快速创建部署 Cloud Volumes ONTAP"^]。



[[troubleshooting-and-recovery]]
== 故障排除和恢复

如果您在完成前离开引导流程，或者代理部署失败，请使用此部分。这些步骤可帮助您从中断处继续操作，或恢复并重试部署。



[[resume-setup]]
=== 恢复设置

如果在完成之前离开，则可以从上次完成的步骤恢复设置。

.步骤
. 转到 NetApp Console 主页。
. 选择*Resume setup*以继续启用程序。




[[recover-from-deployment-failure]]
=== 从部署失败中恢复

如果部署失败：

.步骤
. 下载部署报告。
. 查看您的配置和日志。
. 选择*Start over*以重试部署。
+
link:https://docs.netapp.com/us-en/console-setup-admin/task-troubleshoot-agent.html["了解如何排查代理问题"^]。
