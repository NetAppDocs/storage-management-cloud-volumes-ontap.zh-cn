= 了解 Cloud Volumes ONTAP 自动化选项
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
DevOps 团队使用各种工具来自动设置和管理其数据中心运行时环境。除了 NetApp Console 之外，您还可以使用其中几种技术来实现 Cloud Volumes ONTAP 自动化，包括 NetApp Console API、ONTAP CLI 过程和自动化工具，如 Ansible 和 Terraform。外部自动化工具通常基于基础架构即代码 （IaC） 设计。

使用 https://labondemand.netapp.com/["Lab on Demand"^]练习自动化 Cloud Volumes ONTAP。



[[netapp-console-apis]]
== NetApp Console API

NetApp Console 提供 REST API，可用于以编程方式管理 Cloud Volumes ONTAP 资源。API 支持创建和管理 Cloud Volumes ONTAP 系统以及在 Amazon Web Services (AWS)、Microsoft Azure (Azure) 和 Google Cloud 上添加聚合和卷等操作。可用的 API 调用因云提供商和部署类型而异，包括单节点和高可用性 (HA) 配置。

您可以使用 Cloud Volumes ONTAP API 工作流来自动化典型部署和后续存储管理。一些工作流包括准备部署、创建系统和管理存储，以及针对 AWS、Azure 和 Google Cloud 的提供商特定工作流。
