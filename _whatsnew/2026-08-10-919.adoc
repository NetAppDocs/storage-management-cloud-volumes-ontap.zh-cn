[[cloud-volumes-ontap-9-19-1]]
=== Cloud Volumes ONTAP 9.19.1

您现在可以使用 NetApp Console 在 Amazon Web Service (AWS) 和 Google Cloud 中部署和管理 Cloud Volumes ONTAP 9.19.1 的 General Availability (GA) 版本。此版本无法在 Microsoft Azure (Azure) 中进行部署和升级。

https://docs.netapp.com/us-en/cloud-volumes-ontap-relnotes/["了解有关此版本Cloud Volumes ONTAP的更多信息"^]。



[[ability-to-convert-node-based-licenses-to-capacity-based-licensing-in-private-mode]]
=== 能够在私有模式下将基于节点的许可转换为基于容量的许可

NetApp 很高兴宣布针对私有模式 Cloud Volumes ONTAP 部署的基于容量的许可。您现在可以通过将基于节点的许可证转换为基于容量的许可来优化私有模式 Cloud Volumes ONTAP 部署的成本。对于您的私有模式部署，您可以直接从 NetApp 购买 Essentials（自带许可证或 BYOL）包，其容量与您现有的基于节点的许可证相似。

此转换选项支持 NetApp 的分阶段计划，即从基于节点的许可转向基于容量的许可。与为每个系统分配固定容量的基于节点的许可不同，基于容量的许可从 Cloud Volumes ONTAP 系统的共享容量池中提取，使您能够在存储需求发生变化时更灵活地重新分配工作负载。
