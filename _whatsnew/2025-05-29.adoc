=== 已为 Cloud Volumes ONTAP 9.15.1 启用私有模式部署

您现在可以在 AWS、Azure 和 Google Cloud 中以私有模式部署Cloud Volumes ONTAP 9.15.1。  Cloud Volumes ONTAP 9.15.1 的单节点和高可用性 (HA) 部署均启用私有模式。

有关专用模式部署的详细信息，请参见 https://docs.netapp.com/us-en/console-setup-admin/concept-modes.html#restricted-mode["了解BlueXP部署模式"^]。
